Predicting NFL games with a factor pipeline

Can a development-economics method predict football? Testing Rich Abundant Factors on fifteen seasons of NFL plays, and what worked instead.

Over the summer of 2026, I worked with Prof. Arun Chandrasekhar, a Stanford development economist, to test whether his Rich Abundant Factors (RAF) method, a statistical and machine learning technique, could predict NFL games.

Using R, I cleaned data from NFLfastR covering more than 770,000 plays from 2010 to 2025 and built momentum variables (each team’s stats from its last three games). However, the method needs many similar elements to find signal, and NFL games are too different from each other, so RAF failed in this application.

So I switched to a random forest classifier in Python, using averaged momentum variables and some fixed conditions. With this, I predicted the 2025 season with 60% accuracy, compared with a 53% baseline for always picking the home team, and 65.83% when the Vegas spread was added.

The cleaned dataset and the Python model are in my public GitHub repo, so anyone can reproduce the results.

Extended

The full story

Why the NFL?

Over the summer of 2026, I worked with Prof. Arun Chandrasekhar, a development economist at Stanford. He developed a rigorous statistical and machine learning method called Rich Abundant Factors (RAF). It gives us a systematic way to find similar components inside an experiment and map how they interact with each other. The method was built and tested mostly for development economics experiments, so I wanted to see how far it could take us!

Curious whether I could drop out of Stanford and become a millionaire by gambling, I decided to apply Prof. Chandrasekhar’s method to predicting NFL games. This was nothing like what the method was designed for, but as the saying goes: “Math does not care” (or something like that, I am citing my professor on this one).

The goal

Predict NFL game outcomes using only momentum variables (stats that capture how well each team has been playing recently) for both teams, plus a few static variables (fixed conditions of the game, like the type of field and the wind).

The catch

RAF needs many elements that are similar enough to each other, so it can pick up signal from how groups of similar things interact. Every NFL game is so different from the others that this is hard, and it is the bread and butter of sports prediction.

Building the dataset

I spent many hours coding in R, cleaning a dataset from NFLfastR, a public database of more than 770,000 NFL plays from 2010 to 2025. I chose variables based on my own judgment and Claude’s about what matters in a game. Some were dropped along the way because of missing data or because they were hard to standardize across 15 years.

Fitting the NFL into RAF

RAF relies on Singular Value Decomposition (SVD). To use it, the data has to be split into two sides, which show up as the “columns” and “rows” of an interaction matrix. I assigned the home team’s variables to the columns and the away team’s to the rows.

That left my static variables out of scope, since they belong to the game as a whole and not to either team. I could have added them back with a linear regression (a standard method for fitting a line through data) on each cell of the grid, but that would have pulled me away from RAF’s original method, and I wanted to keep it as pure as possible. So I worked only with momentum variables.

Running RAF: a big null result

Next, I created lagged momentum variables, meaning each team’s stats from their last three games, and ran RAF. The goal was for the method to sort games into a small number of labeled groups, called factors, using two tools: weighted least squares (WLS), a regression that gives more weight to more reliable data points, and varimax rotation, which sharpens the groups so each game clearly belongs to one.

As Jack, a PhD candidate and coauthor of the RAF paper, and I had expected, RAF could not find enough similarity between games to label them cleanly. I tried averaging the lagged variables to create more look-alike games and tested yards completed and final score as different outcome variables (the thing the model tries to predict), but nothing worked.

Only three NFL games showed strong signal, each tied to a different factor, and every other game had basically 0.0000000000000000000000000… What a bummer!

Plan B: a random forest

After this big null result, I accepted that if I wanted to get rich gambling, RAF was not the tool for this job. So I switched to a standard random forest classifier in Python. I averaged each team’s last three games of momentum variables and added back my static variables, then used the model to predict the 2025 NFL season.

Results

The model picked the right winner about 60% of the time, against 53.38% for always picking the home team. Adding the Vegas spread (the point margin set by sportsbooks) raised accuracy to 65.83%.
